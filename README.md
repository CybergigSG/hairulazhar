# Hairul Azhar — Portfolio

Static portfolio site. Open `index.html` directly, or deploy the whole folder (`index.html` + `assets/`) to any static host (EdgeOne Pages, Netlify, GitHub Pages).

- `assets/img/` — product screenshots and live captures of client sites
- `assets/video/` — KatalockAi-generated showreel (compressed H.264, 720p)
- `resume.html` / `resume-2page.html` — résumé (3-page and 2-page), styled by `resume.css`
- `assets/Hairul_Azhar_Resume_Full.pdf`, `assets/Hairul_Azhar_Resume.pdf` — PDFs printed from those pages (open the HTML in Chrome and Print → Save as PDF to regenerate)
